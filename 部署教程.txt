# 部署到Railway

## 步骤1: 安装Git
下载安装: https://git-scm.com/download/win

## 步骤2: 创建GitHub仓库
1. 打开 https://github.com/new
2. 仓库名: mahjong-slot
3. 点 "Create repository"

## 步骤3: 上传代码
打开PowerShell，运行:
```powershell
cd "C:\Users\赵新松\Desktop\mahjong-deploy"
git init
git add .
git commit -m "initial"
git remote add origin https://github.com/你的用户名/mahjong-slot.git
git branch -M main
git push -u origin main
```

## 步骤4: Railway部署
1. 打开 https://railway.app
2. 用GitHub登录
3. 点 "New Project" → "Deploy from GitHub repo"
4. 选择 mahjong-slot 仓库
5. 等待部署完成

## 步骤5: 获取链接
部署完成后，Railway会给你一个链接，如:
https://mahjong-slot.up.railway.app

把这个链接发给朋友就能玩了!
